# Nodo Work Café ☕
### UX/UI Case Study | 2026

Nodo Work Café is a responsive web and mobile experience designed to simplify workspace reservations and coffee orders through an AI-powered assistant.

## 👩‍💻 My Role
UX/UI Designer

I designed the end-to-end experience, from user research and information architecture to high-fidelity prototypes and usability testing.

## 🎯 The Challenge
Users need a simple and efficient way to find available workspaces, make reservations, and order coffee without navigating through complex processes.

The goal was to explore how an AI assistant could simplify these tasks while maintaining a clear, intuitive, and trustworthy experience.

## 🔎 Design Process
- User Research
- Personas & Journey Mapping
- Information Architecture
- User Flows
- Wireframing
- UI Design
- Design System
- Interactive Prototyping
- Usability Testing
- Iteration

## 🛠 Tools
Figma · FigJam · Maze · Notion

## 🧪 Usability Testing
I conducted a usability test in Maze with participants to evaluate the workspace reservation flow.

The testing helped identify opportunities to:
- Provide more workspace information before confirmation.
- Improve the visual hierarchy of the primary CTA.
- Make editing a reservation easier.

These insights were incorporated into the final design.

## ✨ Results
✔ Complete AI-assisted reservation flow  
✔ Responsive desktop and mobile experience  
✔ Usability-tested and iterated design  
✔ Scalable Design System with reusable components
